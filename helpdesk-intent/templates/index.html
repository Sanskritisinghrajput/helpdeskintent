How it works

  1. Data. Institutional helpdesk queries labelled account, certification, complaint, process, technical. Built-in corpus by default, or real CLINC150 / Kaggle intent data mapped onto those categories.
  2. Models. A TF-IDF + logistic regression baseline, Bi-GRU and Bi-LSTM networks trained from scratch, and a fine-tuned BERT.
  3. Confidence. Each model outputs class probabilities. The top probability is the confidence.
  4. Fallback. If confidence is below the threshold, the query goes to a human agent instead of a possibly-wrong desk. The threshold is tuned on validation data using genuine out-of-scope queries (weather, jokes, sports…) the models never trained on.

Tip: try “What's the weather today?” — a good model should refuse to guess.
